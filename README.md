# Sales Data Analysis and Data Cleaning Project 

## Project Overview 

This project focuses on cleaning, transforming, analyzing, and visualizing a large sales dataset containing over 100,000 records.

The project demonstrates the complete Data Analyst workflow:

- Data Cleaning
 
- Data Validation 

- Exploratory Data Analysis (EDA)
 
- Business Insights
 
- Power BI Dashboard Development 

## Tools Used 

- Python
 
- Pandas
 
- NumPy
 
- Matplotlib
 
- Seaborn
 
- Power BI
 
- Jupyter Notebook
 
## Dataset Information 

Raw Dataset:
 
sales_raw_data_dirty_100k.csv

 
Clean Dataset:
 
sales_clean_data_100k.csv

 
## Data Cleaning Activities
 
- Removed duplicate records
 
- Standardized regions
 
- Standardized payment methods
 
- Converted quantity to numeric format
 
- Converted unit prices to numeric format
 
- Parsed multiple date formats 

- Recalculated TotalSales 

- Handled missing values 

- Performed final validation
 

## Key Findings 

- Electronics generated the highest revenue. 

- Phones generated the highest product sales. 

- Central region produced the highest revenue. 

- PayPal was the strongest payment method. 

- Revenue was evenly distributed across sales channels.
